# Donor Impact Visualizer (SmileLog)

An interactive Java application designed for donors to track their contributions and clearly visualize the real-world social impact their donations create.

## Overview

Donors often wonder how their contributions are actually used and what difference they make. This application gives donors a transparent, tangible look at the outcomes driven by their giving—such as meals provided, educational kits funded, or families supported. By making social impact tangible and measurable for donors, the tool helps non-profits strengthen transparency, engagement, and donor retention.

## Features

- **Donor-Facing Impact Tracking:** Allows donors to view tangible social outcomes generated by their contributions.
- **Fund Allocation Breakdown:** Visualizes how donations are distributed across specific community programs and initiatives.
- **Milestone & Tier Calculations:** Dynamically models outcome metrics across different donation levels.
- **Object-Oriented Design:** Clean domain models with modular business logic and separation of concerns.
- **Unit Testing:** Core calculation logic and data integrity verified with JUnit test suites.

## Tech Stack

- **Language:** Java 
- **Testing:** JUnit 5
- **Architecture:** Object-Oriented Design (OOD)
- **Version Control:** Git & GitHub
