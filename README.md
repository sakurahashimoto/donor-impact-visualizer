# Donor Impact Visualizer (SmileLog)

A Java desktop application that lets donors see the direct community impact of their contributions, helping non-profits stay transparent and connected with supporters.

## Overview

When people donate to non-profits, they rarely get to see the actual result of their money. SmileLog lets donors track their donations and converts those dollar amounts into concrete milestones (e.g., meals provided, school kits distributed, or families assisted). This gives donors a clear view of their impact and helps non-profits build trust with their community.

## Features

- **Impact Metrics:** Translates donation amounts into concrete deliverables (meals, supplies, services funded).
- **Program Breakdown:** Shows how funds are split across different projects and initiatives.
- **Milestone Tracking:** Calculates progress toward community funding goals.
- **Unit Tested:** Core calculation logic and edge cases covered with JUnit.

## Tech Stack

- **Java **
